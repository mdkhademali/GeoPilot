# Development
`npm ci` → `npm run build` (re-run after changes, or `npm run dev` for watch builds) → reload the extension in `chrome://extensions`.
Scripts: `typecheck`, `lint`, `test`, `format`, `icons` (regenerates PNG icons from SVG), `package`. Figures are generated by `node scripts/make-figures.mjs`.
Conventions: strict TypeScript, pure logic in `features/*/*.ts`, shared styling via CSS variables and `gp-*` component classes in `src/styles/index.css`.
