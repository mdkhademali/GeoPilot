# User Guide
- **Popup:** search tools, open one in the side panel, toggle theme, save the current page or selection.
- **Side panel:** sidebar groups tools; star a tool to favorite it; Ctrl/⌘+K opens the command palette.
- **Dashboard:** counts come from your saved data (items, notes, bookmarks, favorites, recent tools).
- **Coordinates:** choose a mode, enter values; invalid input shows a message. Copy any result.
- **Spectral indices:** enter *scaled* reflectance. Division by zero is reported, not hidden.
- **GeoJSON:** paste, review the report, format/minify, copy or download.
- **Research:** click the toolbar icon on the page first, then *Save current page* / *Save selected text*. DOI lookup labels Crossref-retrieved metadata separately from your own entries.
- **Citations:** export saved references as BibTeX, RIS or JSON; import BibTeX, RIS or CSL-JSON.
- **Settings:** theme, JSON backup/restore (restore replaces current data), clear all data (confirmation).
